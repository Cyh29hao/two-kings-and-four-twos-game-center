# PR #7 整合审查

PR 将可选的斗地主 v3 扩展赛制接入现有三游戏应用。经典规则、德州操作区、麻将页面、统一动画缓存和玩家数据继续沿用 main；不包含数据库迁移和新站点。

## 整合结果

- 保留 main 的轻量牌桌、统一倒计时、紧凑聊天、断线及超时出牌禁用、牌桌详情和结算摘要；接入 v3 商店、装备窗口、教程与战报。
- 修复商店期底牌泄露、多人查看底牌串用、复制日志暴露私有点数和提前返回装备队列。地主确定后进入装备窗口不会遮回已公开底牌。
- 修复装备结算后行动权归属、跳过赌注吞掉后续机会、满手牌无法使用站起来跟他打、农民无法触发断你财路、首次购买随机复制装备延迟一局生效。
- 拒绝重复牌实例与非法目标；修复接龙与普通顺子的压制关系、接龙每局次数、精确复制上限计算、系列替换和双向互斥、人脉跨局次数以及商店确认后的交易。
- 四带二转移直接选择目标；商店显示实际升级价；固定三人赛制开始后离桌会结束整桌并释放成员，避免后来者继承其他人的资产；斗地主战报筛选包含 v3。
- 保留 45 个冻结装备 ID 和旧快照解释；两件未实现装备仅保留设计记录，不可购买、不在玩家图鉴中宣称可用。原有经典与已退休装备快照测试继续保留。

## 验证口径

- 全量 check（素材、类型、规则、框架与文档）、正式构建和正式产物本地 API smoke 均通过。新增可重复种子的 12 桌完整赛制回归，覆盖终局、非负金币和手牌实例唯一性。
- 本地接口关闭开发者权限，验证三游戏、聊天、德州操作，以及三名独立用户的一整局 v3、版本冲突拒绝、成员权限和离桌清理。
- 2026-09-17 实际点击正式产物：三游戏与战报导航、浏览器前后退、v3 建房、教程、商店购买、完成购买、竞价、选牌出牌、文字聊天、表情发送、刷新后恢复房间。
- 使用独立本地末手夹具，实际点击出牌后确认整桌冠军、金币与胜利点，随后从斗地主筛选打开已保存的战报。末手夹具不等同于人工打完全部赛程；完整对局由引擎和 API 自动验收覆盖。
- 在手机尺寸检查牌桌、手牌与聊天入口，未出现横向溢出；页面运行日志未见错误。没有声称逐一手动点验全部 43 件装备，也未操作线上真实牌局。

发布前仍需对合并后的 main 执行 release:prepare，发布后执行 release:verify；本文件中的本地结果不能代替线上核验。
