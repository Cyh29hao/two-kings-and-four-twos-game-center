# 回放与精彩 TV：交付说明

## 本轮完成

- 观看以原牌桌为主体：投稿者在下方，其余玩家在原座位明牌，保留当局昵称、公共牌、出牌结果及聊天表情。约一秒自动开始，聊天依次播放。
- 播放控制独立占位。信息与投稿收进「这一局」，推荐语在牌桌外显示；逐步记录按需打开。终局留在牌桌，支持再看一遍，麻将结算主动查看。
- 个人回放、精彩 TV 与错误状态按账号和请求绑定；过期请求不覆盖新页面。TV 保留筛选和分页，私人记录保持本人视角，公开 TV 使用投稿者视角。
- 条件撤稿/下架保留管理员墓碑；技能版补齐操作完成后的真实快照。构建核对实际客户端资源，消除不存在的辅助预加载，并拒绝真实入口或依赖缺失。

## 验证

- `npm run check`：372 项测试通过。
- `npm run build`：正式构建通过，两份客户端资源清单通过校验。
- `npm run test:smoke`：最终 668 项检查通过（随机对局使数量浮动）。
- Edge 正式产物：320×568、390×844、844×390、834×1112、1024×768、1440×900。检查最大手牌、最长出牌、终局、密集麻将、四/六/十人德州及经典三人渲染夹具。牌面无横向滚动，播放控制可达；德州额外核对公共牌与各家底牌不交叠。
- 实际点击：TV 筛选返回、匿名/昵称及推荐语投稿、暂停、进度与记录跳步、最后一刻暂停、错误恢复、同路由换账号隔离。模拟第二页和视角响应仅用于验证前端路由契约；真实服务端权限、视角和撤稿另由烟测覆盖。
- 修复资源问题后六项浏览器流程复验通过，无非预期控制台错误。新增资源校验八项回归，覆盖真实缺失文件拒绝及失败不部分改写。

## 发布边界与资料限制

代码交付在 PR #24，合并和正式发布由项目负责人决定。没有自动合并、部署、改站点身份或迁移线上玩家数据。

较早对局缺少存档时无法补回回放；历史技能商店或结算缺资料时不生成虚构商品/方案。缺失独立响应时间戳的多人操作不编造思考秒数。短屏和密集牌桌可在播放器内纵向滚动，控制独立保留。生产负载和实体手机触摸未纳入本地验收。
