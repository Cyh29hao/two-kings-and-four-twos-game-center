# 固定局数友谊赛

## 玩家流程

普通三人斗地主、欢乐三打一、麻将、德州建房时选择自由对局或 1、4、8、12 局。自由对局是默认值，旧房间不改变。技能斗地主继续使用原来的胜利点赛制。

第一局实际发牌后固定名单，不能换人或替换人机。局间仍需准备；只统计成功结算的唯一对局。无人叫地主重发不计局；麻将流局、连庄后的新一局和德州弃牌结算都计局。中止退款不计局。

普通斗地主累计积分，麻将、德州累计净筹码变化；补筹码不算盈利。最高成绩相同则并列冠军。打满后服务端拒绝继续开局、原子释放占座，最后的牌局和战报保留。主动提前结束或名单无法维持时保留已结算成绩，不颁冠军。

牌桌上的“本场成绩 / 本场结算”可随时打开和关闭。首次完成时短暂播放现有国王、公主素材，减少动态效果或关闭牌桌特效时使用静态王冠。刷新和轮询不重复颁奖。整桌战报中的“查看牌桌”可返回原桌查看最后结果。

- 独立于尚未合并的回放 PR，从 main `9b19520` 开始。

- 友谊赛专项：160 项真实本地 API 断言通过，包括三/四人斗地主并发末手只结算一次、账户分数只更新一次、麻将真实流局、德州真实弃牌结算、名单锁定、占座释放、N+1 拒绝、战报权限和提前结束。

## 尚未通过的验证

全量 `npm run test:smoke` 在本地 Wrangler 对故意构造的拒绝请求后出现代理请求流异常，后续请求得到 503 或超时。已用独立预览复现：未消费请求体的拒绝响应可影响下一次请求；这发生在友谊赛用例之前。未重试任何写请求来掩盖失败。反馈接口先读取原有受限 JSON 再校验登录，修复了该接口未登录有效 JSON 的触发路径；跨站等拒绝路径的全量环境问题仍未解决。

GitHub CI 是独立的最终门槛，PR 在取得结果前保留草稿状态。物理手机触摸、Safari 和线上延迟未实测；本轮手机证据来自 Edge 浏览器设备尺寸模拟。
