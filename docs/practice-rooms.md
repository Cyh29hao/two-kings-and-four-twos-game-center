# 人机测试房

建房参数 `mode: "practice"` 创建单人测试房，默认省略或 `friends` 保持好友房。斗地主补两位陪练；新版基础麻将与 ham 规补三位。机器人仅为房间座位，不创建用户、密码、会话或成员表记录。禁止其他真人加入。

`lib/practice/landlord.ts` 使用有预算的手牌分组搜索，结合控牌、保炸弹、队友让牌及末张拦截；`mahjong.ts` 结合结构距离、公开可见余牌、实际合法进张和后期风险。策略输入仅含自己的牌和公开信息，不接收其他手牌或牌墙。ham 胡牌方案按最高倍数及固定顺序确认，不能查看隐藏奖牌。此版本是启发式进阶陪练，没有专业棋力评级。

`room.ts` 填充座位并安排下一次机器人操作，约 0.9 秒后可推进，由现有 1.5 秒页面轮询驱动，一次处理一步。机器人自动准备，真人点击准备后开始下一局。响应窗口过期时仍遵循引擎的放弃规则。真人选赖子保留 60 秒和明确确认步骤。所有人离开页面时暂停主动推进，恢复访问后处理到期操作，与既有房间机制一致。

每次推进沿用 `rooms.ts` 的版本校验和原子提交，防止重复请求、多端轮询与关闭竞争重复执行。斗地主人机房保留局内输赢及记录，但不修改账号积分。麻将继续独立筹码、负余额及战报。房主可随时结束测试；麻将未完成局记中止并退回当前局杠费，之前局数和收支保留。

房间、记录及过滤后的分享快照增加可选 `practice` 和座位 `bot` 标记，不新增表、不改变已有规则版本。页面和导出图片明确标记人机测试。回退代码必须认识人机房元数据和积分隔离，不能让旧的无机器人调度代码接管进行中的人机房。

验证：`npm test` 包含策略行为、隐藏信息不影响决策及 24 局机器人模拟；`tests/practice-api.test.ts` 仅访问 localhost，用三个测试账号分别跑斗地主、ham 和基础麻将各两局，验证原子推进、真人确认、账号积分隔离、续局、结束退款、战报与实体牌守恒。本地数据库和账号凭证禁止打包发布。
