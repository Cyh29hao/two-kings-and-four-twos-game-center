# 斗地主扩展赛制 `landlord-v3` 规则草案

> 状态：需求草案。本文只记录已确认的玩法决定，并将会改变服务端行为的未决问题明确列出。实现、测试和 PR 以本文的后续定稿为准。

## 1. 范围与兼容

- `landlord-v3` 是建房时可选的扩展赛制；现有经典斗地主 `landlord-v2` 的规则、房间状态和历史战报不得改变。
- 每桌固定三名玩家。金币、胜利点和装备均只属于本桌赛制，不写入账号娱乐积分，也不迁移到其他房间。
- 所有金币金额在服务端使用十进制字符串和 `BigInt` 计算；客户端不得提交可信的余额、价格、结算额或胜利点。
- 每项可改变规则效果的装备都必须由服务端校验；房间创建时保存完整的规则和装备目录快照。

## 2. 整桌赛制

### 2.1 常规胜利

- 玩家作为地主获得单局胜利时，获得 `1` 胜利点。
- 玩家作为农民获得单局胜利时，获得 `0.5` 胜利点。
- 任一玩家累计达到 `4` 胜利点，立刻获得本桌最终胜利，赛制结束。
- 地主和农民方的单局胜负仍由斗地主出完牌规则决定：地主先出完牌则地主胜；任一农民先出完牌则农民方胜。

### 2.2 局数上限与突然死亡

- 常规赛最多进行 `12` 局。
- 第 `12` 局结束后，若无人达到 `4` 胜利点，进行第 `13` 局突然死亡。
- 第 `12` 局结束时，胜利点并列最低的每名玩家各获得 `8` 金币补偿。
- 第 `13` 局不再存在地主、农民、叫地主、抢地主或加倍。
- 第 `13` 局为三人各自为战：三名玩家互为对手，任一玩家首先出完自己的手牌，立即获得本桌最终胜利。
- 第 `13` 局不再使用胜利点、阵营胜负、赌注、炸弹倍数、春天或反春天结算来决定冠军。

## 3. 第 13 局发牌与出牌

- 三人各发 `18` 张牌，使用整副 `54` 张牌，不留底牌。
- 沿用常规斗地主的合法牌型与压制关系：单张、对子、三张、三带一、三带二、顺子、连对、飞机、四带二、炸弹和王炸。
- 沿用“连续两名其他玩家不出后，由上一手出牌者重新领出”的出牌流程。
- 乱斗局中的每位其他玩家均为对手；不适用农民让牌、队友判断或阵营策略。
- 本局不进入叫地主、抢地主、个人加倍或阵营结算阶段。

## 4. 庄家、叫地主与抢地主

### 4.1 庄家

- 每局由庄家开始叫地主。
- 首局庄家随机指定；此后庄家每局按座位顺序轮换。

### 4.2 竞价

- 庄家开始叫地主。
- 首位叫地主者需要下注 `1` 金币。
- 进入抢地主阶段后，按座位顺序进行。选择抢地主的玩家，下注额为上一位抢地主者下注额加 `1` 金币。
- 选择不抢的玩家跳过本次机会，流程继续至下一位玩家。
- 同一名玩家可以在经过一轮后再次抢地主。下注额没有规则设定的最高上限。
- 最后一名抢地主者之后，其他两名玩家连续选择不抢时，抢地主结束；最后一名抢地主者成为地主。
- 若三名玩家首次均不叫且至少一名玩家持有金币，则当前金币数量最多的玩家强制成为地主，并支付 `1` 金币。多人并列最高时，从本局庄家开始顺时针，首位并列者成为地主。
- 若三名玩家首次均不叫且所有玩家金币均为 `0`，本局不支付金币，也不执行地主相关的金币结算规则；本局庄家成为地主，以继续正常发牌和出牌流程。

## 5. 金币经济

### 5.1 初始与收入

- 每桌开始时，每名玩家拥有 `2` 金币。金币是局前商店购买装备与叫地主/抢地主下注之间的抉择资源，不存在独立保证金。
- 每局比赛结束后，每名玩家获得 `1` 金币。
- 每局比赛中首先出完牌的玩家额外获得 `1` 金币。
- 金币无欠债：任何需要支付金币的结算，玩家余额不足时只收取其当前可用余额。

> 第 `13` 局决定整桌冠军后，不发放本节的每局基础金币或首先出完牌金币奖励。

### 5.2 地主赌注结算

- 赌注金额为最终地主的下注额。
- 地主获胜时，若最终赌注为偶数，地主分别从两名农民处收取“下注金额除以 `2` 再加 `1`”的金币。若最终赌注为奇数，剩余手牌较少的农民支付 `floor(下注金额 / 2) + 1`，剩余手牌较多的农民支付 `ceil(下注金额 / 2) + 1`；两名农民剩余手牌相同时，从本局庄家开始顺时针遇到的首位农民支付较高一份。余额不足的农民被收取全部可用余额，不产生欠债。
- 农民方获胜时，两名农民瓜分地主下注的金币。下注金额为偶数时平分；为奇数时，本局首先出完牌的农民多获得 `1` 金币。

- 玩家被后续抢地主者取代时，其已下注金币立即返还至可用余额。
- 玩家只有在可用金币足以覆盖本次下注额时才能叫地主或抢地主；下注发生时，下注额立即从可用余额转入托管。
- 最终地主的下注持续托管至本局结束。地主获胜时，托管金币返还地主，再执行两名农民向地主的付款；农民方获胜时，地主托管金币作为两名农民的分配池。

## 6. 局前商店与装备

### 6.1 商店

- 每个常规局开始前打开商店；每名玩家拥有独立商店。
- 每名玩家的商店在每个等级最多随机展示 `3` 件装备；某等级目录不足 `3` 件时，展示该等级全部候选装备。
- 商店每局刷新一次。
- 装备等级与标价固定为：一级 `1` 金币、二级 `2` 金币、三级 `4` 金币、四级 `8` 金币。
- 装备价格越高，设计强度应越高。
- 装备购买后持续至本桌赛制结束，包括第 `13` 局；总持有装备数不得超过 `8` 件。
- 每局不限制购买装备件数，但购买后不得超过 `8` 件持有上限。
- 玩家可以出售已持有装备。二级、三级和四级装备按原价一半获得金币；一级装备售出不获得金币。
- 一级装备“额外刷新”允许其持有者额外刷新一次当前商店中尚未购买的候选；已购买候选不刷新。

### 6.2 已提出的装备

| 等级 | 装备 | 当前描述 |
| --- | --- | --- |
| 一级 | 额外刷新 | 可以在商店中刷新一次。 |
| 一级 | 搞一张 | 开局时获得随机手牌的一张复制；不会创造新的合法牌型。 |
| 二级 | 未定 | 尚无具体装备。 |
| 三级 | 史密斯夫妇 | 每次出牌时，J 和 Q 可任选互相替代。对子和炸弹按替代后较大的点数判定；顺子和飞机按可组成合法顺子或飞机的替代方式判定。 |
| 三级 | 13 恐惧症 | 玩家出牌后手牌恰好剩余 13 张时可开始点击；A=1，2=2，王不能弃。可一次公开弃掉任意张总点数为 13 的手牌。 |
| 四级 | 超级炸弹 | 使用炸弹或王炸时可触发；玩家自行选择额外弃掉 1 至最多 4 张手牌，不要求恰好 4 张，牌不足 4 张时仍可触发。 |
| 四级 | 王炸！！！ | 每桌全体玩家共限一次。持有者在正常出牌时打出王炸，立即结算本局胜利；常规局中本局胜利点翻倍，突然死亡局中立即获得整桌胜利。 |

- 长期目标为每个等级约有 `15` 件装备。

### 6.3 已确认的第 13 局装备关系

- 第 `13` 局前是否照常刷新商店尚未最终确认。
- 已持有装备是否在第 `13` 局持续有效尚未最终确认。
- 任何依赖地主、农民、赌注、叫地主、抢地主、加倍、春天或反春天的装备，在第 `13` 局必须禁用或定义替代效果。

## 7. 装备实现约束

下列语义已定，需在服务端牌型判定、私有装备状态和人机策略中一致实现。

| 项目 | 已定规则 |
| --- | --- |
| 生命周期与持有量 | 装备持续至整桌结束；持有上限为 8 件；每局购买数量不限，但不能超过上限。 |
| 出售 | 二级至四级按标价一半出售；一级出售不返还金币。 |
| 搞一张 | 复制牌必须拥有独立实例 ID；只能参与既有标准斗地主牌型，不得形成五张同点、重复王炸或其他新增牌型。 |
| 史密斯夫妇 | 每次出牌动作需提交 J/Q 的替代声明。对子和炸弹按较大点数判定；顺子、飞机选择能构成标准连续牌型的映射。 |
| 13 恐惧症 | 只在玩家出牌后剩余恰好 13 张时提供一次公开弃牌机会；A=1、2=2、王不可弃；本次所弃任意张牌的点数总和必须为 13。 |
| 超级炸弹 | 炸弹和王炸均可触发；玩家自行选择额外弃掉 1 至最多 4 张手牌；手牌不足 4 张不阻止触发。 |
| 王炸！！！ | 同一桌全局仅能成功触发一次。持有者必须在其正常出牌回合打出王炸；常规局立即结束，胜利点翻倍；第 13 局立即结束并由该玩家获得整桌胜利。 |

## 8. 超时、离桌、人机与公开信息

- 常规局需要为商店、叫地主、抢地主和装备触发定义独立超时默认动作。
- 第 `13` 局的人机必须使用三方互为敌人的策略，不得复用“农民让牌”或队友信息。
- 公开接口返回所有玩家已持有装备的类型与等级；仅本人可见完整装备实例与私有商店。其他玩家的手牌、商店候选和未触发装备效果不得提前公开。
- 所有状态推进继续使用房间版本校验和现有原子事务；重复请求、掉线恢复和机器人自动操作均不得重复扣款、发放金币或结算胜利点。

## 9. 实现验收要点

- 为 `landlord-v3` 写独立引擎测试，保留所有 `landlord-v2` 测试。
- 验证金币不能变成负数；每笔托管、返还和支付均在同一原子提交中完成。
- 验证每个常规局和乱斗局的牌实例守恒；有复制牌时验证虚拟实例不会与原牌混淆。
- 验证第 `12` 局后的补偿只发一次，第 `13` 局只产生一名最终冠军。
- 验证旧房间和旧战报继续以 `landlord-v2` 解释；新房间保存 `landlord-v3` 快照。
