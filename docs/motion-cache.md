# 动画缓存

- 三游戏与图鉴共享窗口级 Cache Storage，仅允许清单中的公开 WebP。没有 Service Worker，不拦截登录、聊天、牌局或任何 API；请求不携带账号凭据，写入缓存的响应只保留图片数据和类型。
- `scripts/build-motion-cache.mjs` 根据实际文件生成大小及 SHA-256 摘要。开发启动和构建都会校验并更新清单。缓存键使用图片路径与内容摘要，更新某张图只替换该图；旧消息的素材保持独立 ID。
- 发送中的 21 个表情与全部 15 个牌型标识，共 63 份封面/帧图集约 13 MB。入桌或进入图鉴后延迟开始，每次只预取一份；页面隐藏时暂停启动新下载，启用节省流量或 2G 时不自动预取。用户可主动点“缓存全部动画”，失败后继续补齐缺少部分。
- 同一图的并发请求共用 Promise。完整图集先异步解码后绘制；解码缓存按引用计数保留使用中的图片，空闲部分限制 32 MiB。磁盘缓存始终存压缩图片，不把整包全部解码进内存。
- 悬停/键盘聚焦提前解码当前图。本机图鉴与聊天重播从解码完成后开始；实时消息继续使用原始开始时间与截止时间，不补播过期事件。逐帧播放只在帧编号变化时提交 React 状态，停顿帧不反复渲染。
- 不可用、满额或清理后的浏览器缓存均可回退普通加载。HTTP 错误、HTML 页面或大小不符的数据不会进入缓存；解码失败会删除该缓存项。缓存不是永久承诺，浏览器可按空间限制清理。

## 验证

`tests/motion-cache.test.ts` 覆盖跨页面离线复用、十路并发去重、更新仅下载变更图片、缓存失败降级、失败重试、错误页面不入库、全量清单和实际文件摘要。现有牌局/聊天/时序测试继续回归。

本地 Chrome 验收确认自动缓存完成、刷新保持完成状态、表情和牌型播放器 `data-ready=true`，完整牌型图鉴图片无缺失。

API 依据：[Cache](https://developer.mozilla.org/en-US/docs/Web/API/Cache)、[异步图片解码](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/decode)。
