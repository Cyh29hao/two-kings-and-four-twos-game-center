# 三游戏牌桌轻量化验收

本轮基于包含 PR #2 的 main（7479243）。只调整牌桌、行动区和结算摘要；后续按用户要求加入统一确认和按前注倍数下注；新规则使用 holdem-v2，旧 v1 保持兼容，不迁移数据库。UI PR 等用户决定合并，尚未发布。

## 改版对照

| 场景 | 改版前 | 改版后 |
| --- | --- | --- |
| 德州等待 | 四种动作、金额输入、上下限和说明同时常驻 | 动作始终可选；选中显示勾选，统一确认在等待时置灰 |
| 德州自己的回合 | 预选与直接行动并排，确认含义不突出 | 所有动作均先选择，只有统一“确认”提交；加注面板不再有单独确认按钮 |
| 德州加注 | 金额表单一直占用空间 | 主动展开金额面板，区分“加注至”和“本次投入”；全下在面板内 |
| 本人信息 | 桌上和操作区重复底牌、金额、名字与倒计时 | 自己的手牌集中到底部，桌上保留身份和下注标记；当前行动倒计时一处显示 |
| 斗地主 | 常驻选牌说明、数量说明和清空按钮 | 选牌后才显示清空；非法牌型或不能压过才提示 |
| 麻将响应 | 每个组合一条长按钮 | 先选择吃/碰/杠；同类多个组合用牌图选择，再明确确认 |
| 结算 | 默认铺开玩家收支、倍数解释 | 突出结果、本人净变化和准备下一局；完整计算在牌桌详情 |
| 辅助入口 | 房间聊天文字按钮、分散规则与日志入口 | 图标入口保留可访问名称和提示；规则、收支、日志集中到牌桌详情 |

- `npm run check`：151 项测试通过，TypeScript、素材清单和文档链接通过。
- `npm run build`：正式构建通过。
- `npm run test:smoke`：68 项本地隔离检查通过，含三游戏、机器人补位、聊天权限/幂等/冷却、房间版本冲突及德州等待预览。
- 真实浏览器点击正式构建（本机隔离数据库，不使用线上玩家凭据）：
  - 德州等待时预选跟注 30；上一玩家加注至 80 后，跟注按钮更新为 80 并显示金额变化提示，统一确认在本回合启用；确认前本人仍为 990，确认后为 910，行动转到下一玩家。
  - 翻牌阶段预选过牌后，另一玩家下注，过牌预选取消；原金额低于新下限时保留输入并禁用加注确认。
  - 刷新后旧预选清空；再次点击同一动作可取消，切换动作及填写金额均不提交下注。
  - 斗地主实际准备、叫 3 分、不加倍、选择一张牌、点击出牌；选牌显示抬起/按下状态，提交后手牌由 20 张变为 19 张且“清空”消失。
  - 麻将单击选牌时仍为 14 张，仅选中一张；点击出牌后变为 13 张，弃牌进入完整弃牌区。
  - 麻将同一张 3 万有三种吃牌方案：未选组合时确认禁用；选第二组并确认后副露为 2/3/4 万。
  - 麻将自摸、选择 16 倍方案、逐张翻两张奖牌、本人 +480 的结算摘要与准备下一局入口。
  - 德州 4/6/10 人桌；桌面、窄屏和矮窗口。十人桌座位边界不相交，操作区与牌桌相隔约 12 px；窄屏页无整体横向溢出，牌桌内保留横向滚动。
  - 52 张牌通过四批摊牌展示逐一覆盖；DOM 几何核对点数区与装饰花色无交叠、点数未越出牌框。保留原扑克和麻将牌面组件。
  - 表情点击后立即在本人头像出现；显示 3 秒冷却；窄屏发送后面板自动收起。聊天文字提交后仅有一条；三游戏切换和聊天入口正常。

自动测试与浏览器验收分别记录：断线重连、换街、换手、全下限制、筹码不足以及版本冲突的完整组合继续由既有预选逻辑测试和 API 冒烟覆盖；没有声称逐一人工模拟所有网络故障或多端时序。

## 统一确认与下注单位追加验收

动作入口始终显示，不再有“提前选择”或“确认加注”。所有选择只改变本地选中状态，统一确认在等待、未选动作、金额非法和提交中禁用。实际浏览器验证：本人回合输入 81 时确认禁用，改为 90 后启用；确认后筹码从 990 变为 900。下一玩家回合输入合法 150 时确认仍禁用。服务端非倍数请求返回 400，拒绝时房间状态不变。

新增规则测试覆盖前注单位、非倍数拒绝、最小加注向上取整、跟注/全下余数、超大整数精度和 v1 兼容；当前共 151 项测试、68 项冒烟检查通过。前注为 0 时单位为 1，避免零除；已开 v1 房间不变。
