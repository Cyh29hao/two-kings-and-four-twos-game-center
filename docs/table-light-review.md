# 三游戏牌桌轻量化验收

本轮基于包含 PR #2 的 main（7479243）。调整牌桌、行动区和结算摘要，并按用户要求加入统一确认、前注倍数下注和前注计入翻牌前投入；新规则使用 holdem-v3，旧 v1/v2 保持兼容，不迁移数据库。UI PR 等用户决定合并，尚未发布。

## 改版对照

| 场景 | 改版前 | 改版后 |
| --- | --- | --- |
| 德州等待 | 四种动作、金额输入、上下限和说明同时常驻 | 动作始终可选；选中显示勾选，统一确认在等待时置灰 |
| 德州自己的回合 | 预选与直接行动并排，确认含义不突出 | 所有动作均先选择，只有统一“确认”提交；加注面板不再有单独确认按钮 |
| 德州加注 | 金额表单一直占用空间 | 主动展开金额面板，区分“加注至”和“本次投入”；全下在面板内 |
| 本人信息 | 桌上和操作区重复底牌、金额、名字与倒计时 | 自己的手牌集中到底部，桌上保留身份和下注标记；当前行动倒计时一处显示 |
| 斗地主 | 常驻选牌说明、数量说明和清空按钮 | 选牌后才显示清空；非法牌型或不能压过才提示 |
| 麻将响应 | 每个组合一条长按钮 | 先选择吃/碰/杠；同类多个组合用牌图选择，再明确确认 |
| 结算 | 默认铺开玩家收支、倍数解释 | 突出结果、本人净变化和准备下一局；完整计算在牌桌详情 |
| 辅助入口 | 房间聊天文字按钮、分散规则与日志入口 | 图标入口保留可访问名称和提示；规则、收支、日志集中到牌桌详情 |

## 统一确认与下注单位追加验收

动作入口始终显示，不再有“提前选择”或“确认加注”。所有选择只改变本地选中状态，统一确认在等待、未选动作、金额非法和提交中禁用。实际浏览器验证：本人回合输入 81 时确认禁用，改为 90 后启用；只有确认后才扣款。下一玩家回合输入合法 150 时确认仍禁用。服务端非倍数请求返回 400，拒绝时房间状态不变。

新增规则测试覆盖前注单位、非倍数拒绝、最小加注向上取整、跟注/全下余数、超大整数精度和 v1 兼容；当前共 156 项测试、68 项冒烟检查通过。前注为 0 时单位为 1，避免零除；已开 v1/v2 房间不变。

## 实时投入与动作反馈

- 每位玩家座位前显示金色“投入”筹码标记，数字为服务端提供的本手累计投入 `total`，换街保留；提示中可查看本轮下注 `bet`。
- 跟注／加注／过牌／全下／弃牌使用服务端结构化动作字段，文字与颜色同时区分，不解析日志或昵称。当前行动者仍只有一处倒计时。
- 新投入短暂弹动，动作标签短暂强调；参数登记在统一 motion catalog，无新增下载素材。普通轮询、初次载入与换手不反复播放；关闭特效、减少动态效果或后台页面时不播放。
- 正式构建实点：先投入 10，选择“跟注 20”并在本人回合确认，座位显示“投入 30”和“跟注”，剩余 970。自动验证四家跟齐后底池 120、换街累计投入保留、再次下注累计增加及中止退款。
- 6/10 人桌再次检查窄屏：座位边界无重叠，操作区与牌桌相隔 12 px，页面不产生整体横向溢出。
- v3 前注计入翻牌前下注，盲注只补到 20/30；前注不得高于小盲。v1/v2 继续额外收前注，已有牌局和战报不回写。

## Sites 二进制图片缓存兼容

- 接收 Sites 返回的 `application/octet-stream`，先校验大小、RIFF/WEBP 文件头以及素材清单中的 SHA-256 版本，再转成 `image/webp` 用于播放及持久缓存。错误 HTML 与同大小被修改内容均拒绝。
- 集成测试对全部 63 个激活动画使用真实素材与二进制 MIME：自动队列完成 63/63；重复启动不重新下载；新页面离线读取测试通过。约 1.8 秒自动启动以及省流量、2G/slow-2G 暂停逻辑保持不变。
- 当前完整检查共 159 项测试通过，构建通过，68 项隔离冒烟通过。重新构建后在浏览器表情页实际点击选择和重播，显示全部动画已缓存，无控制台错误。二进制响应通过测试注入验证，未把本地预览视为线上发布验证。

## 本次投入输入方式

金额输入改为本人这次再投入的筹码，实时显示将付出及剩余。提交边界才换算成服务端本轮累计目标，未改规则或接口；等待时不提交、金额变化保留输入、统一确认与 BigInt 校验仍在。浏览器正式产物实测：已投入 10、余额 990，等待时输入 80，实时显示将付出 80 / 剩余 910，确认不可点击；轮到本人后点击确认，累计投入 90、余额 910，动作记录本次投入 80。完整检查 160 项测试、构建、68 项冒烟通过。
